¿Qué es HTML?

Introducción

HTML es el Lenguaje de Marcado de Hipertexto (HyperText Markup Language) que se usa para crear y estructurar las páginas de internet.

¿Qué son las etiquetas?

Estructura básica

La inmensa mayoría de las etiquetas funcionan como "cajas" que envuelven al contenido y tienen tres partes principales:

  1. Etiqueta de apertura "": Indica dónde empieza el elemento. Usa los símbolos menor que (<) y mayor que (>).
  2. El contenido: El texto, imagen o elemento que va dentro.
  3. Etiqueta de cierre "": Indica dónde termina el elemento. Es igual a la de apertura, pero lleva una barra diagonal (/) antes del nombre.
